# KOSISH ADHIKARI PORTFOLIO

A premium digital archive showcasing my professional journey and technical expertise in Computing and Networking. This project serves as a comprehensive record of my academic history, projects, and specialized skills.

## CORE FEATURES

* SECURITY PROTOCOL ENTRANCE
The site features a unique entry system using a rock paper scissors minigame to initialize the archive. This adds a playful layer of security and interaction for every visitor.

* DYNAMIC TYPING ANIMATIONS
Content across the site reveals itself through smooth typing effects that trigger as you scroll. This creates an engaging reading experience that feels alive and responsive.

* INTERACTIVE CUSTOM CURSOR
A specialized mouse trail follows the pointer across the screen, enhancing the tactile feel of the user interface.

* RESPONSIVE DARK MODE DESIGN
The entire portfolio is built with a sophisticated dark aesthetic, utilizing glassmorphism and subtle gradients for a high end visual appeal. It works perfectly on both desktop and mobile devices.

* STICKY NAVIGATION SYSTEM
A smart header hides or shows based on scroll direction to maximize screen space while keeping essential links accessible at all times.

## TECHNOLOGY STACK

* HTML5 for structural semantic foundation
* VANILLA CSS for complex animations and styling
* JAVASCRIPT for logic and interactive systems
* GOOGLE FONTS for premium typography

## PROJECT STRUCTURE

* index.html : Primary profile and academic timeline 
* projects.html : Portfolio of technical works 
* skills.html : Catalog of technical and soft skills 
* experience.html : Professional history and leadership roles 
* certificates.html : Validated academic and training records 
* contact.html : Direct communication gateway 
* style.css : Unified design system and animations 

## INSTALLATION AND USAGE

1. Clone the repository to your local machine.
2. Open index.html in any modern web browser.
3. Win the security protocol minigame to access the full content.
